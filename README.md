# Projeto MotoGestor - Sistema de Gerenciamento de Estoque para Oficinas Mecânicas de Motocicletas

# Peculiaridades de Configuração

- ## A IDE utilizada para o desenvolvimento completo do sistema foi a NetBeans, especificamente a versão 8.2;

- ## A versão do JDK recomendada para que se não tenha problemas durante a compilação do projeto é a JAVA 8 (1.8);

- ## Sobre as dependências, as bibliotecas necessárias estão localizadas na pasta `\lib` e precisam ser referenciadas manualmente no VS Code caso o projeto não as reconheça automaticamente.
